# premium-furniture-shop

Интернет-магазин премиум мебели для дома на базе статической HTML/CSS/JS страницы.

## Как запустить

1. Откройте файл `index.html` в браузере напрямую, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
```

2. Перейдите по адресу:

```text
http://localhost:8000
```

## Что включает проект

- Главная страница с hero-блоком и брендом
- Каталог товаров с фильтрами
- Карточки премиум мебели
- Корзина с добавлением товаров
- Разделы коллекций, преимуществ и отзывов
- Адаптивный дизайн под мобильные устройства

## Используемые технологии

- HTML
- CSS
- JavaScript
- Unsplash для изображений
